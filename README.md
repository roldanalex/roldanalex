**Full-Stack Data Scientist & Sr. Data Engineer** — 20 years in biopharma manufacturing, 13 in data roles. I own the AI & analytics platform portfolio for a plasma fractionation site, anchored by an R/Shiny manufacturing analytics platform of ~84,000 production lines serving ~150 daily users on a 15-minute refresh cycle.

> **I build production GenAI that isn't allowed to guess** — deterministic code computes every number; the language model is only allowed to narrate it.

## About

- Eight years operating the plasma fractionation process as a manufacturing technician, then five analyzing it as an operations analyst — the floor-level process knowledge behind every model and platform I've built since.
- In a GxP environment, a chatbot that invents a batch yield isn't a bug — it's a compliance event. My GenAI architectures restrict the language model to interpretation while deterministic code computes all statistics; in production, that design also cut token consumption by ~70%.
- 30+ production solutions shipped, including 3 production RAG systems.
